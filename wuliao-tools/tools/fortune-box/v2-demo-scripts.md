## 句式结构拆解

**好的 explanation 节奏**：
1. 前1-2句：顺着 answer 拉满期待（假象）
2. 中间1-2句：突然反转，出现意外细节
3. 最后1句：收尾暴击，必须是扎心真相，不能是鸡汤

**坏的 explanation**：
- 全程说理，没有具体场景
- 结尾是感悟/鸡汤/鼓励
- answer 和 explanation 方向不一致

# 无厘头盲盒卜卦生成器 · 设计规格书

> **版本**：v1.0 | **日期**：2026-08-21 | **制定**：老虾 + 大哥
> **专题**：017-无厘头实验室

---

## 一、产品愿景

一个「无厘头盲盒卜卦生成器」—— 用户输入任意内容，AI 生成出奇制胜的无厘头命运盲盒，打开后播放一个出人意料的动画。

核心体验：**神秘感 → 期待感 → 意外惊喜**

双模式设计：
- **展示模式**：简洁神秘，只留时钟+输入框+按钮（给外人玩）
- **设置模式**：大哥自定义氛围/动画/音效（自己配置）

---

## 二、核心流程

```
用户输入任意文字
      ↓
AI 解读 + 无厘头化 → 生成 { 类型, 文案, 参数 }
      ↓
随机路由到某动画模块
      ↓
播放动画（出奇制胜）
      ↓
保存记录 → 可回放/导出
```

## 五、AI 生成协议

### 输入 Prompt 结构
```
当前时间: {timestamp}
用户输入: {user_input}
随机种子: {random_seed}
风格: {style}
要求: 生成一个无厘头的卜卦结果，必须出奇制胜

返回JSON格式:
{
  "type": "prediction|timetravel|prank|mystic|badluck",
  "title": "标题（10字内）",
  "text": "无厘头文案（20-50字）",
  "params": {
    // 类型特定参数，驱动动画
  }
}
```

### 多样性保障（三层随机）
1. **用户输入层**：最大变量，同一话不同时间抽也不同
2. **AI生成层**：时间戳+随机数注入Prompt
3. **动画路由层**：同文案可映射多个动画，动画内部也有随机参数

```json

  "style": "dark-mysterious",

    "text": "你将在3秒后打喷嚏",

  },
  "animation_id": "anim_007",
  "animation_module": "prediction_sneeze",
  "created_at": "2026-08-21T15:31:00+08:00"

```

### 存储方案
- **localStorage**：展示端，JSON 数组
- **JSON文件备份**：大哥本地存档
- **飞书多维表格**（可选）：同步到云端

## 十一、系统通知生成器（新模式 v2.0）

> **新增时间**：2026-08-25 | **制定**：老虾 + 大哥

### 1. 产品定位

「系统通知生成器」是「逆天改命」工具的全新模式。
用户输入一个愿望或问题 → 系统用「官方系统通知」格式输出 → 冷漠公示 + 隐藏反转 → 精准戳中打工人痛点。

**核心体验**：期待感（系统说你愿望实现了）→ 冷漠感（全是公文格式）→ 沉默（仔细看细节）→ 暴击（反转来了）

### 2. 两种模式对比

| 要素 | 改命模式（原有） | 系统通知模式（新增） |
|------|----------------|-------------------|
| 交互 | 抽签 → 动画揭示 | 输入愿望 → 直接展示 |
| 输出 | 玄学预言 + 动画 | 系统通知窗口 |
| 语言 | 神秘、仪式感 | 冷漠、公文格式 |
| 反转 | 说出来 | 藏在细节里 |

### 3. 系统通知视觉规范

```
┌─────────────────────────────────────┐
│ ● ● ●         系统通知              │  ← 窗口标题栏（红绿小点）
├─────────────────────────────────────┤
│                                       │
│  【系统通知】您的"XX"申请已提交...   │  ← 主标题（加粗）
│                                       │
│  ✅ 检测到您今日新增资产：+8,000,000 │  ← 绿色（好事）
│  ⚠️ 您的在职状态：已离职             │  ← 红色（反转）
│  ⚠️ 您的社保状态：已中断             │  ← 红色
│  ℹ️ 您的银行卡单笔限额：500.00元     │  ← 灰色（补刀）
│                                       │
│  ─────────────────────────────────   │
│  【提示】客服热线：12345（市话收费）  │  ← 最后补刀
│                                       │
└─────────────────────────────────────┘
```

**配色规范**：
- 窗口背景：`#1e1e1e`（深灰，模拟系统窗口）
- 标题栏：`#2d2d2d`
- 红色警告：`#ff4d4d`
- 绿色成功：`#4dff88`
- 灰色提示：`#888888`
- 白色主文字：`#e0e0e0`
- 分割线：`#3a3a3a`
- 字体：等宽字体（Consolas / Monaco / monospace）

### 4. 文案生成逻辑

#### 4.1 愿望分类 → 模板路由

| 类型 | 关键词 | 核心反转逻辑 |
|------|--------|-------------|
| 不想上班 | 不想当牛马、想辞职、不想打工 | 申请批准了，但没有任何补偿 |
| 一夜暴富 | 想发财、想有钱、中彩票 | 钱到账了，但你也"不是打工人"了 |
| 准时下班 | 想下班、想回家、到点就走 | 到点下班了，但工作被带回家做了 |
| 被理解 | 没人理解我、孤独、没人懂 | 有人理解了——是AI，但你得付费 |
| 涨薪 | 想加薪、想涨工资、工资太低 | 加薪成功，但是因为公司普调，你反而倒退了 |
| 社保公积金 | 社保、公积金、买房 | 社保没问题，但你没资格买了 |
| 身体健康 | 身体健康、不想加班、想休息 | 批准了，住院去了 |

#### 4.2 每类模板结构

```
【系统通知】您的"XX"申请已提交，请等待处理。
↓（1-2秒后）
处理完成。
↓
【结果】XX（批准/实现）
↓
【详细】
  · 实际结果1
  · 实际结果2
↓
【补充说明】
  （根据条款/规定：反转原因）
↓
【提示】
  （最后补一刀）
```

## 十二、好友许愿模式（新模式 v3.0）

> **新增时间**：2026-08-25 | **制定**：老虾 + 大哥

### 1. 产品定位

「好友许愿」是「逆天改命」工具的第三种模式。用户输入对好朋友的愿望 → 系统用玄学系统通知格式输出 → 表面祝福好友，实际上讨要好处的整蛊内容。

**核心体验**：真诚祝福 → 系统认证你是好朋友 → "作为系统我都觉得你太好了" → 暗示好处 → 引导 @好友

### 2. 内容结构

```
【命运系统 · 好友许愿通道已开启】

您的愿望：想让好朋友发财

系统分析：
优先想到朋友，而不是自己
您的善良指数：超标
您的体贴指数：超标

您的好朋友【自动屏蔽】将会获得：
- 财运持续涌入
- 意外之财降临
- 贵人运爆棚

作为系统
我都觉得您对朋友太好了
我相信您的朋友肯定会特别感激您
哪怕是一杯奶茶
一顿饭呢
您说呢？

@您的好朋友
告诉他系统已为他开启
```

### 3. 模式识别

| 模式 | mode 参数 | 结果页渲染 |
|------|----------|-----------|
| 改命模式 | `fortune` | FortuneRenderer 刮刮乐动画 |
| 系统通知 | `notify` | SystemNotificationRenderer 系统通知窗口 |
| 好友许愿 | `friend-wish` | SystemNotificationRenderer 系统通知窗口（玄学风格） |
